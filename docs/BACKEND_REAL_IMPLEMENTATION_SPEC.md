## 2. KẾ HOẠCH TRIỂN KHAI THEO 10 VERTICAL SLICES TUYẾN TÍNH

Chúng ta sẽ thực hiện tuần tự 10 Vertical Slices theo chuỗi dữ liệu thực cốt lõi:
```text
SLICE 1: Công trình  ──>  SLICE 2: Quan trắc  ──>  SLICE 3: Cảnh báo  ──>  SLICE 4: Hồ sơ  ──>  SLICE 5: Evidence
      │
      └──>  SLICE 6: Nhiệm vụ  ──>  SLICE 7: Dashboard  ──>  SLICE 8: Báo cáo  ──>  SLICE 9: Thông báo  ──>  SLICE 10: Cài đặt
```

### Tiêu chí nghiệm thu (Definition of Done) cho mỗi Slice:
1. **D1 SQLite Persistence**: Toàn bộ thao tác đọc/ghi đều truy vấn trực tiếp vào D1 SQLite (`prisma/dev.db` / `env.DB`).
2. **Zero Mock**: Không còn bất kỳ mảng fake, số ảo fallback dạng `|| 12`, `alert(...)` giả lập nào trên luồng chính.
3. **DevTools Verification**: Kiểm tra trực tiếp trên Chrome DevTools (Network HTTP 200/201, Console 0 error, F5 reload còn nguyên dữ liệu).
4. **Targeted Tests Pass 100%**: Chạy và vượt qua test suite liên quan (`node --test app/tests/<target>.test.js`).
